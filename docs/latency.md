# Mouth-to-ear задержка

Замер по PLAN.md §4.7: сервер возвращает наш собственный звук через
`VoiceTargetLoopback` (ID 31), движок гоняет полный конвейер на синтетических
кадрах. Число покрывает encode → транспорт → murmur → приём → прайминг
джиттера (`JitterStartMs`) → decode → микшер. Реальные устройства добавляют
сверху период и ring capture/playback (порядка 20–40 мс суммарно).

Методика: тест `TestMouthToEarLoopback` (internal/audio/latency_live_test.go)
на локальном дев-стенде. Пять циклов «unmute → первый слышимый кадр на выходе»,
между циклами передача закрывается терминатором и джиттер праймится заново —
это задержка начала новой реплики, худший случай для слушателя.

Сигнал — настоящая речь (testdata/speech_48k.wav, macOS TTS), с тишиной между
циклами. Это не косметика: RNNoise за секунды выучивает как шум любой сигнал,
который никогда не замолкает или точно повторяется, — синус, периодический
«слоговый» паттерн и даже апериодический гармонический дрон без формант были
подавлены вживую (три провалившихся варианта задокументированы в тесте).
AEC3 в замере выключен: в loopback возвращённый поток и есть эхо-референс,
сошедшийся канцеллер его (корректно) стирает; алгоритмической задержки AEC3
не добавляет. Gate тоже вне замера — он меряет порог VAD, а не тракт.

Запуск:

```sh
task murmur:up
go test -tags live -count=1 -run TestMouthToEarLoopback -v ./internal/audio
```

## Результаты

| Дата | Форма тракта | Медиана | Мин–макс | Заметки |
|---|---|---|---|---|
| 2026-08-22 | M2 (без DSP), синус | 95 мс | 85–99 мс | первый замер, тональный сигнал |
| 2026-08-22 | M2 (без DSP), речь | 110 мс | 105–117 мс | Apple Silicon, murmur v1.5.915 в докере, loopback |
| 2026-08-22 | M3 (APM NS low + RNNoise) | 128 мс | 112–135 мс | тот же стенд и сигнал |

Бюджет §4.7 — ≤ 250 мс на хорошей сети. Пол тракта: ~80 мс праймит джиттер,
остальное — фазы 10-мс тиков, кодек и фронт нарастания речи до порога
слышимости. На реальной сети сверху ложатся TCP RTT/2 и рост джиттер-буфера
при берстах.

**DoD M3 по латентности выполнен:** M3 − M2 = 128 − 110 = **+18 мс** при
бюджете RNNoise ~20 мс (окно 50% + отложенный кадр ветки main). Замеры на
одном сигнале в одном прогоне.
