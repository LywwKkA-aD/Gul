# Gul

Gul **0.8.0-alpha.1** — приложение для голосового общения, чата и демонстрации
экрана со звуком. Клиент полностью переведён на Electron, TypeScript и LiveKit JS.
Официальный Xray включён в приложение: отдельно устанавливать прокси не нужно.
Исходные цвета Gul сохранены: тёмная боковая панель, светлый чат и синий акцент;
каналы, участники и управление расположены как в привычных голосовых приложениях.

## Подключение

Укажите полный профиль `livekit+vless://…`, выданный владельцем сервера, свой ник
и отдельно пароль. Вход, сигнализация, голос, чат и экран проходят через
VLESS + REALITY по TCP; прямой сетевой fallback отсутствует. Старые профили
клиентов 0.6/0.7 и их установки автоматически не мигрируют.

Адрес и ник сохраняются после успешного входа. Пароль сохраняется только при
явном согласии и доступном защищённом Electron `safeStorage`. На Linux
небезопасный backend хранения не используется: при недоступном keyring пароль
нужно вводить снова.

## Возможности

- Голосовые каналы, текстовый чат и RTT активного медиасоединения.
- Mute/deafen, выбор микрофона и вывода, входной уровень и усиление,
  активация голосом с порогом/задержкой, WebRTC AEC/NS/AGC.
- Громкость участника 0–200% и локальное отключение без потери настройки.
- Демонстрация до 720p/30 FPS, отдельный стереозвук, выбор просмотра,
  его громкость, остановка просмотра и полноэкранный режим.
- Клавиша микрофона в режиме переключения; удержание зависит от адаптера ОС.
- Экспорт ZIP диагностики без адресов/IP, профилей, паролей, JWT и текста чата;
  проверка новой версии с открытием проверенной страницы GitHub.

Просмотр чужого экрана не требует разрешения на захват собственного.
История чата хранится отдельно по каналам в памяти текущей сессии.
Смена канала, выход и завершение приложения останавливают захват и соединения.
На Windows/macOS окно можно скрыть в работающий трей; на Linux закрытие
завершает приложение.

## Экран и звук

Демонстрация запрашивает изображение и системный звук вместе. Захват выполняется
внутри приложения после выбора источника; диалог объясняет, какой звук передаётся. Windows 10 и Linux передают общий звук устройства, который
может включать голоса Gul. Чтобы не вернуть их собеседникам, выберите для Gul
другой вывод либо выключите входящий звук Gul на время демонстрации. Наушники
сами по себе не исключают голоса из системного loopback.

На Windows 11 и поддерживаемой macOS клиент запрашивает исключение собственного
звука; результат зависит от ОС и источника. На Linux нужен работающий
PipeWire/PulseAudio, а для Wayland — desktop portal. Выбор окна не означает,
что звук ограничен только этим приложением.

Проверены настоящие Electron-клиенты с голосом, чатом и синтетическими
видео/стереозвуком через удалённый REALITY сервер, включая 20 циклов демонстрации.
Это проверка медиатранспорта. Захват конкретной игры Windows 10 ↔ Ubuntu 26,
часовая игровая сессия и нагрузка на этих компьютерах требуют отдельного теста.

## Установка

Целевые артефакты: Windows 10+ x64 — NSIS EXE и ZIP; Ubuntu 24.04+ x64 — DEB;
macOS Apple Silicon/Intel — отдельные DMG. В установщик входят Chromium и Xray;
Go, Node.js, WebView2 и внешний браузер пользователю не требуются.
Для DEB используйте `sudo apt install ./Gul-*.deb`, чтобы установить зависимости.
Alpha-сборки выпускаются без доверенной релизной подписи/нотаризации;
операционная система может показать предупреждение.

## Разработка

Нужны Node.js 24, npm и Python 3; для transport tests — OpenSSL в PATH.
Go 1.26.7 нужен только для серверного broker, Docker — для локального стенда.

```sh
cd desktop
npm ci
npm run vendor:xray
npm run dev
```

```sh
npm run check
npm run format:check
npm run test:coverage
npm audit --audit-level=moderate
```

`npm run pack` собирает распакованное приложение; `npm run dist -- --publish never`
создаёт установщик для текущей платформы. Windows helper удержания PTT собирается
на Windows с MSVC; его путь и build script находятся в `desktop/native/ptt`
и `desktop/scripts/build-ptt.mjs`.

```sh
go -C server test -race -count=1 ./...
go -C server vet ./...
python3 -m unittest discover -s deploy/livekit -p 'test_*.py'
```

[Локальный REALITY/LiveKit стенд и E2E](deploy/livekit/README.md),
[структура клиента](desktop/README.md), [решения](docs/DECISIONS.md).
Версия клиента задаётся в `desktop/package.json` и lockfile; зависимости
закреплены, Xray проверяется по `desktop/resources/xray/manifest.json`.
