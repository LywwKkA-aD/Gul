# Gul

Gul **0.8.0-alpha.5** — приложение для голосового общения, чата и демонстрации
экрана со звуком. Клиент полностью переведён на Electron, TypeScript и LiveKit JS.
Официальный Xray включён в приложение: отдельно устанавливать прокси не нужно.
Исходные цвета Gul сохранены: тёмная боковая панель, светлый чат и синий акцент;
каналы, участники и управление расположены как в привычных голосовых приложениях.

## Подключение

Укажите полный профиль `livekit+vless://…`, выданный владельцем сервера, свой ник
и отдельно пароль. Вход, сигнализация, голос, чат и экран проходят через
VLESS + REALITY по TCP; прямой сетевой fallback отсутствует. Старые профили
клиентов 0.6/0.7 и их установки автоматически не мигрируют.

Адрес и ник сохраняются после успешного входа. Пароль сохраняется только при
явном согласии и доступном защищённом Electron `safeStorage`. На Linux
небезопасный backend хранения не используется: при недоступном keyring пароль
нужно вводить снова. После перезапуска интерфейс восстанавливает согласие
на сохранение и показывает доступность пароля. Ошибка шифрования или записи
больше не скрывается; заблокированное хранилище можно прочитать повторно.

Если Linux сообщает о блокировке, нажмите «Разблокировать хранилище» в Gul.
Пароль системы вводится в штатном диалоге Ubuntu. Кнопка «Пароли и ключи»
открывает системное управление: найдите хранилище «Вход»/Login и разблокируйте
его. Пароль хранилища мог остаться прежним после смены пароля Ubuntu.
Не удаляйте хранилище: в нём могут быть пароли других приложений.
Gul сообщит, если после разблокировки нужно полностью закрыть и запустить его.
Нечитаемый ciphertext показывается отдельно от реальной блокировки;
ручной ввод и успешный вход с включённым запоминанием позволяют сохранить пароль заново.

## Возможности

- Голосовые каналы, текстовый чат и RTT активного медиасоединения.
- Mute/deafen, выбор микрофона и вывода, входной уровень и усиление,
  активация голосом с порогом/задержкой, WebRTC AEC/AGC и локальный RNNoise.
  Настройки обработки применяются и после входа в канал.
- Громкость участника 0–200% и локальное отключение без потери настройки.
- Демонстрация до 720p/30 FPS, отдельный стереозвук, выбор просмотра,
  громкость просмотра 0–200%, остановка просмотра и полноэкранный режим.
- Клавиша микрофона в режиме переключения; удержание зависит от адаптера ОС.
- Экспорт ZIP диагностики без адресов/IP, профилей, паролей, JWT и текста чата;
  проверка новой версии с открытием проверенной страницы GitHub.

Просмотр чужого экрана не требует разрешения на захват собственного.
История чата хранится отдельно по каналам в памяти текущей сессии.
Смена канала, выход и завершение приложения останавливают захват и соединения.
На Windows/macOS окно можно скрыть в работающий трей; на Linux закрытие
завершает приложение.

## Экран и звук

Демонстрация автоматически запрашивает изображение и системный звук вместе.
Захват начинается после выбора источника; диалог объясняет, какой звук
передаётся. У зрителя есть отдельная громкость демонстрации 0–200%.
На Linux встроенный помощник захватывает звуки приложений и игр отдельно от
процессов Gul. Голоса собеседников, чужие демонстрации и сигналы Gul не попадают
в трансляцию; собеседников по-прежнему слышно. Нужен локальный PipeWire/PulseAudio.
Помощник не меняет устройства вывода/ввода и маршруты приложений. Если отдельный
захват недоступен, общий микс с голосами Gul не используется.

На Wayland выбор делает системный desktop portal, без второго пустого диалога.
Для X11 и других ОС пустые названия источников заменяются на «Экран»/«Окно».
Выбор окна не ограничивает звук только одним приложением.

На Windows встроенный WASAPI helper проверяет доступность process loopback и
исключает дерево процессов Gul из звука демонстрации. Собеседников по-прежнему
слышно в обычном выводе. Поддержка определяется проверкой API при запуске,
а не только номером Windows. Если API недоступен, передаётся изображение без
системного звука; общий микс с голосами Gul не используется. На macOS
исключение собственного звука запрашивается у Chromium/ОС и зависит от источника.

Выбор экрана/окна на Windows и X11 находится внутри Gul: превью, вкладки и
отдельное подтверждение вместо ряда кнопок с названиями окон. На Wayland
сохраняется системный portal picker. Смена канала и отмена закрывают выбор.

Шумодав использует встроенный RNNoise в AudioWorklet микрофона; сеть ему не
нужна. Обработка работает на 48 kHz и добавляет около 30 мс алгоритмической
задержки. Демонстрация передаёт stereo без голосового шумодава. Автоматические
сравнения используют открытую запись речи и синтетический шум вентилятора/
клавиш; качество физического микрофона и конкретной клавиатуры проверяется на ПК.

Проверены два настоящих Electron-клиента с голосом, чатом и синтетическими
видео/стереозвуком через обновлённый удалённый REALITY сервер, включая 20 циклов
демонстрации. Linux native capture на X11/Xvfb/PulseAudio стенде
подтвердил движущиеся кадры в пределах 720p и stereo PCM через TURN/TCP.
В alpha.2 настоящий Linux capture передал тестовую игру 440 Гц L / 660 Гц R
с разделением 49 дБ; собственный звук Gul 880 Гц исключён на 52 дБ,
обычный вывод сохранил игру и Gul. Физический микрофон, игра Windows 10 ↔ Ubuntu 26,
удержание PTT и часовая игровая сессия ещё требуют проверки. Wayland на Ubuntu 26
проверяется на целевой машине отдельно от X11 CI.

Alpha.3 дополнительно проверяет 12 запусков/остановок в одиночном канале,
подключение третьего зрителя после публикации и повторный вход. Все фактические
publisher offers/answers проверяются на VP8 BUNDLE конфликт и ошибки применения
SDP; bitrate hint сохраняется. Очистка старой демонстрации не закрывает новую.

## Установка

Целевые артефакты: Windows 10+ x64 — NSIS EXE и ZIP; Ubuntu 24.04+ x64 — DEB;
macOS Apple Silicon/Intel — отдельные DMG. В установщик входят Chromium и Xray;
Go, Node.js, WebView2 и внешний браузер пользователю не требуются.
Для DEB используйте `sudo apt install ./Gul-*.deb`, чтобы установить зависимости.
Все четыре цели прошли CI packaged smoke с работающим sandbox: Windows x64,
Linux x64 и macOS arm64/x64. Linux DEB в этом тесте действительно установлен.
Windows CI runner не заменяет проверку Windows 10 на компьютере пользователя.
Alpha-сборки готовятся без доверенной релизной подписи/нотаризации;
операционная система может показать предупреждение.

## Разработка

Нужны Node.js 24, npm и Python 3; для transport tests — OpenSSL в PATH.
Go 1.26.7 нужен только для серверного broker, Docker — для локального стенда.

```sh
cd desktop
npm ci
npm run vendor:xray
npm run dev
```

```sh
npm run check
npm run format:check
npm run test:coverage
npm audit --audit-level=moderate
```

`npm run pack` собирает распакованное приложение; `npm run dist -- --publish never`
создаёт установщик для текущей платформы. Windows helpers PTT и системного
звука собираются на Windows x64 с MSVC: `npm run build:ptt` и
`npm run build:audio`. Linux helpers — `npm run build:ptt` и `npm run build:audio`
с `g++`, `pkg-config`, `libglib2.0-dev` и `libpulse-dev`. Его путь и build script находятся в `desktop/native/ptt`
и `desktop/scripts/build-ptt.mjs`.

```sh
go -C server test -race -count=1 ./...
go -C server vet ./...
python3 -m unittest discover -s deploy/livekit -p 'test_*.py'
```

Локально: 367 unit tests, на macOS 365 passed/2 platform skips; покрытие
TS строк/ветвей/функций — 89.68%/90.39%/88.46%. Unit runner требует минимум
80% по каждой метрике; дополнительно
проверяются реальный Electron, REALITY/TURN и native capture. Windows PTT helper прошёл
регистрацию/освобождение F8 hook, Linux portal — семь DBus сценариев. Физические
клавиши проверяются отдельно. Релизный workflow публикует установщики после
успешных проверок клиента, медиатранспорта и сервера.

[Локальный REALITY/LiveKit стенд и E2E](deploy/livekit/README.md),
[структура клиента](desktop/README.md), [решения](docs/DECISIONS.md).
Следующий этап: [управление каналами только владельцем](docs/CHANNELS.md).
Это архитектурный план; динамические и закрытые каналы пока не реализованы.
Версия клиента задаётся в `desktop/package.json` и lockfile; зависимости
закреплены, Xray проверяется по `desktop/resources/xray/manifest.json`.
